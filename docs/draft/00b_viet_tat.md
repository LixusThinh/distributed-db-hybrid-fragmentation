# DANH MỤC TỪ VIẾT TẮT

Bảng: Danh mục từ viết tắt
| Từ viết tắt | Tiếng Anh | Tiếng Việt |
|---|---|---|
| CSDL | Database | Cơ sở dữ liệu |
| CSDLPT | Distributed Database | Cơ sở dữ liệu phân tán |
| DBMS | Database Management System | Hệ quản trị cơ sở dữ liệu |
| DDBMS | Distributed Database Management System | Hệ quản trị cơ sở dữ liệu phân tán |
| HV | Horizontal – Vertical | Phân mảnh hỗn hợp ngang trước, dọc sau |
| VH | Vertical – Horizontal | Phân mảnh hỗn hợp dọc trước, ngang sau |
| BEA | Bond Energy Algorithm | Thuật toán năng lượng liên kết |
| AA | Attribute Affinity matrix | Ma trận ái lực thuộc tính |
| CA | Clustered Affinity matrix | Ma trận ái lực đã gom cụm |
| PK | Primary Key | Khóa chính |
| 2PC | Two-Phase Commit | Giao thức cam kết hai pha |
| MSDTC | Microsoft Distributed Transaction Coordinator | Bộ điều phối giao dịch phân tán của Microsoft |
| SSMS | SQL Server Management Studio | Công cụ quản trị SQL Server |
